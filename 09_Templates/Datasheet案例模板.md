# Datasheet案例模板

## 案例元信息
填写指引：本表是案例的唯一身份记录，必须逐项填满；任何缺项都要在「参数缺口与待确认」登记。

| 字段 | 内容 |
|---|---|
| Datasheet ID | （逻辑文档 ID，例如 DS-类别-序号；不随文档修订改变） |
| 器件型号 ID | （统一 ID，格式 PART-类别-序号，示例 PART-RES-001；同型号不同封装分别分配） |
| Datasheet 文件名 | （原始文件名，含扩展名） |
| 制造商 | （原厂名称） |
| 产品系列 | （系列名） |
| 器件型号 | （完整订货型号，区分封装与包装后缀） |
| 官方来源 | （获取渠道：原厂官网下载页、代理商授权资料、原厂 FAE 提供；不接受第三方转载站） |
| 文档编号 | （原厂文档编号，如 DOC-XXXX；与文件名不同，须逐字抄录） |
| Datasheet 版本 ID | （绑定具体修订的唯一 ID，例如 DSREV-类别-序号；每次修订新增） |
| 文档版本 | （原厂 rev 号或发布日期，逐字记录） |
| 器件等级 | （车规/工业/消费级，以及原厂声明的温度等级与认证状态） |
| 收录日期 | （yyyy-mm-dd） |
| 提取人 | （角色或 Agent 标识） |
| 复核状态 | （未复核 / 已复核 / 有争议） |

规则：
- Datasheet ID 与器件型号 ID 属于统一 ID 体系，取值与格式见 [[元器件知识库统一ID规范]]；二者通过明确的关联记录建立关系，不要求一一对应：一个型号可关联多个 Datasheet 版本，一份 Datasheet 也可能覆盖多个型号/变体。数据记录必须同时绑定具体器件型号/变体与 Datasheet 版本。
- 官方来源、文档编号、文档版本三项共同构成文档身份；改名、转载、压缩包重命名都不改变文档编号与版本。
- 器件等级决定参数取值能否外推到目标应用；等级不符时须在「WCCA 适用性」说明风险。
- 文档版本更新时，保留旧版本及其数据记录作为历史快照；新版本建立新的 Datasheet 版本 ID，并新增对应数据记录 ID。不得覆盖旧版本的参数值或仅修改版本字段。

> 示例，非真实器件参数：R = 10 kΩ ±1 % @ 25 ℃——仅示范字段如何填写，禁止引用为真实保证值。

注意：本模板只规定字段与写法，示例行不是真实器件参数，Phase 1 使用时整行替换。

## 型号与制造商标识
填写指引：
- **完整型号构成**：拆解型号各段含义（系列、特性代码、封装代码、包装方式）。
- **丝印标识**：器件表面丝印内容与型号的对应关系，说明丝印能否唯一确定型号。
- **订货号清单**：列出本次分析的完整订货号及其器件型号 ID，注明与型号的差别。
- **易混淆型号**：列出同系列中参数不同、容易混用的型号，说明差异点；若易混型号也建档，给出其器件型号 ID。

写作纪律：型号信息只依据原厂 Datasheet 与官方选型手册，不用第三方目录数据。

## 关键参数提取表
填写指引：每个参数一行，十一列全部必填，不得留空；取不到值时填「未提供」并登记缺口。

| 数据记录 ID | 参数 ID | 参数 | 符号 | Min | Typ | Max | 单位 | 测试条件 | Datasheet 页码·表号或曲线号 | 参数性质 |
|---|---|---|---|---|---|---|---|---|---|---|
| （示例 DS-RES-001-P001） | （引用参数 ID，示例 RES-001） | （参数英文名/中文名） | （符号） | （最小值） | （典型值） | （最大值） | （单位） | （温度、输入电压、输出电压、电流或负载、频率、偏压） | （如 p.5 Table 2 / p.9 Fig.4） | （Absolute Maximum Ratings / Recommended Operating Conditions / Guaranteed Electrical Characteristics / Typical Characteristics 之一） |
| DS-RES-001-P001（示例） | RES-001（示例） | 示例参数名（非真实） | R（示例） | 占位（示例） | 10（示例） | 占位（示例） | kΩ（示例） | 温度 25 ℃（示例，非真实） | p.0 Table 0（示例占位） | Guaranteed Electrical Characteristics（示例） |

提取纪律：
- 只抄录 Datasheet 上明确给出的数值，不做换算或插值；确需换算时保留原始值与原始单位，另列换算说明。
- 空列填「未提供」，不填估算值。
- 曲线读出的数值要在「测试条件」注明读点位置与读取误差；「参数性质」记录曲线属于典型特性或其他性质，「取值类型」另标读图值。参数性质与取值类型是两个独立维度。
- 同一参数在多个测试条件下出现多行时，逐行分别登记，各占一个数据记录 ID，不合并且不取平均。
- 参数 ID 必须引用「参数体系」已登记的 ID；本器件特有的、通用文档尚未定义的参数，先在器件入口文档登记参数 ID，再回到本表引用。

### 参数性质与 Min/Typ/Max 的保证性

四类参数性质必须显式标注，不得默认：

| 参数性质 | 英文名 | 本行数值的承诺程度 | 可否作为最坏情况边界 |
|---|---|---|---|
| 绝对最大额定值 | Absolute Maximum Ratings | 生存极限，非工作条件 | 不可以，只用于应力余量判断 |
| 推荐工作条件 | Recommended Operating Conditions | 原厂建议的工作范围 | 可以作为工作点约束，不作为参数极值 |
| 保证电气特性 | Guaranteed Electrical Characteristics | 在给定条件下承诺的极值 | 可以，但须同时登记测试条件 |
| 典型特性 | Typical Characteristics | 典型表现，不构成承诺 | 不可以 |

Min / Typ / Max 三列的保证性质分别记录，不得混填：
- **Min 列**：只有在「参数性质」为绝对最大额定值或保证电气特性时才是保证下限；来自曲线的下限属于读图值，不得写成 Min。
- **Typ 列**：一律为典型值，即使原厂未写「典型」字样也不构成承诺；Typ 不得进入最坏情况计算，只能用于敏感性分析。
- **Max 列**：意义同 Min 列，只有在绝对最大额定值或保证电气特性下才是保证上限。
- **空列**：原厂未给出该极值时留「未提供」，不得用 Typ 顶替 Max，也不得用相邻型号数据补齐。
- **条件缺失**：Min 或 Max 存在但测试条件缺失时，该数值降级为待确认值，禁止直接用于 WCCA。

### 参数测试条件记录要求

「测试条件」列必须细化到七要素，缺项写「未注明」：
- 温度：环境温度、壳温或结温，注明是哪种温度；
- 输入电压：施加在输入端的电压条件；
- 输出电压：输出端电压条件（涉及输出特性的参数必填）；
- 电流或负载：负载电流、负载电阻或负载率；
- 频率：测试信号频率或开关频率；
- 偏压：直流偏置电压，电容容值、磁芯类参数必填；
- 其他必要条件：器件特定条件（如 MOSFET 的 VGS、脉冲宽度/占空比，晶振负载电容，安装/散热条件等）；不适用时写「不适用」，未注明时写「未注明」。

同一行只登记一个条件组合；条件不同即另起一行、另分配数据记录 ID。

## 曲线与图表摘录
填写指引：逐条登记本次引用到的曲线与图表。

| 图表编号 | 图表名称 | 横轴 | 纵轴 | 读取点 | 测试条件 | 曲线性质 | 读图方法 | 读取误差 | 适用范围 | Datasheet 页码 |
|---|---|---|---|---|---|---|---|---|---|---|
| （如 Fig.4） | （曲线标题） | （变量与范围） | （变量与范围） | （本次取的点） | （温度、偏压、负载等基准条件） | （典型特性 / 保证特性 / 实测样例） | （目视读取或按刻度插值，写明读点定位方式） | （目测或刻度精度，如「±半格」） | （该曲线可外推的区间与条件边界） | （页码） |

要求：
- 曲线读数一律标为读图值，不得与表格中的保证值混用。
- 典型曲线读数不能自动作为保证边界：曲线通常只代表典型样品在基准条件下的表现，既要承担读图误差，也不包含原厂的 Min/Max 承诺，因此不能直接塞进最坏情况计算。
- 如确需用曲线数据支撑结论，必须走两步：第一步把读图值登记为读图值并写明读取误差；第二步按工程假设值处理，登记评审记录与适用边界，且在结论中标明该段边界的保守性来源。
- 说明曲线的测试基准条件，尤其是温度与偏压；基准条件不同的两张曲线不得拼接使用。
- 若曲线与表格数值冲突，以表格保证值为准，并把冲突登记到「参数缺口与待确认」。

## 工程解读
填写指引：
- **参数含义落地**：把每个关键参数翻译成对电路行为的影响（例如纹波、损耗、裕量变化方向）。
- **设计影响**：说明这些参数如何在选型中形成取舍，哪几个参数是主要矛盾。
- **风险点**：指出参数极端组合下可能出现的问题，并给出对应的参数 ID 组合。
- **结论边界**：说明本案例结论只适用于哪些工作条件，超出后需重新评估。

要求：每条结论后标注依据（参数 ID、页码或数据记录 ID），不写无依据的经验判断。

## WCCA 适用性
填写指引：按六类取值逐类处置本案例提取到的数值，不得自创分类。

| 取值类型 | 本案例中属于该类的参数 | 能否进入 WCCA 结论 | 处置动作 |
|---|---|---|---|
| 保证值 | （列出取得 Min 或 Max 保证值的参数 ID） | 可以 | 直接进入映射总表，登记数据记录 ID |
| 典型值 | （只有 Typ 列的参数 ID） | 不可以 | 只做敏感性分析，或按工程假设值另立一行 |
| 读图值 | （仅从曲线读出的参数 ID） | 不可以直接使用 | 登记读取误差后，按工程假设值走评审 |
| 计算值 | （由已登记数值推导的参数 ID） | 可以 | 保留公式 ID、输入参数 ID 与计算过程 |
| 工程假设值 | （资料不足时的临时取值） | 有条件使用 | 必须有评审批准记录与适用边界 |
| 待确认值 | （尚未确认或存在争议的参数 ID） | 不可以 | 登记缺口，责任人跟进，确认日期闭环 |

补充要求：
- **映射登记**：把可参与计算的参数按 09_Templates/WCCA参数映射模板.md 的字段登记，保持与本案例参数表一致；映射只引用参数 ID 与数据记录 ID，不复制数值。
- **不重复维护**：同一数值只在本表登记一次，映射表与结论文档只引用数据记录 ID。

|---|---|---|---|---|---|---|---|

- 不得自行补齐数据；未确认前相关结论必须标为待确认值，并同步登记到 99_Management/待确认问题.md。
