# 元器件通用知识模板

## 模板使用说明
本模板是器件类别入口文档的统一写作骨架，覆盖统一知识文档要求的全部章节。

使用步骤：
1. 复制本文件到目标器件目录，重命名为「器件名_索引.md」。
2. 保留全部二级标题及其顺序，不得增删、不得改写标题文字。
3. Frontmatter 中 status 先填 planned；正文填完自检后改 draft；评审通过后改 reviewed。
4. 每节按「填写指引」逐条替换为实际内容，删除指引前确认要点已覆盖。
5. 参数值必须附测试条件与 Datasheet 出处；取不到出处时只能写「未提供」或「待确认」。
6. 保存后更新 updated 字段，并在 99_Management/更新记录.md 登记本次变更。

### Frontmatter 填写规则

八个基础字段见 00_Home/知识库建设说明.md 的 Frontmatter 约定；本模板在此之上新增两个统一 ID 字段：

| 字段 | 必填 | 取值规则 |
|---|---|---|
| component_class_id | 是 | 器件类别 ID，取自 [[元器件知识库统一ID规范]] 的类别注册表；本模板使用待填写占位符；复制后必须填写已登记的真实类别 ID，不得沿用占位符 |
| id_schema_version | 是 | 所遵循的 ID 规范版本号；规范升主版本时必须复核并同步本字段 |

规则：
- 类别 ID 一经分配，不因文档改名、目录移动或版本更新而改变；废弃类别的 ID 不重新分配。
- 入口文档正文只引用类别 ID 与参数 ID，不重复定义这两个标识的含义（定义在规范里写一次）。

### 参数 ID 与 N/A 规则

- 每个参数在「参数体系」表首列登记参数 ID，格式为「器件类别 ID + 三位流水号」，示例 ID 仅用于说明格式，不作为可复制的实际分配值。参数 ID 在此处分配后全库通用，案例文档与 WCCA 映射只引用、不重定义。
- 本器件确实不具备某参数类别时，可在该类别小节写 N/A，并在同一行写明原因（例如「该类器件无此参数」「原厂不提供该类指标」）。N/A 必须带理由，不允许留空或只写「无」。
- N/A 不能用来掩盖资料缺失：本应有但查不到的参数写「未提供」，并登记到案例文档的「参数缺口与待确认」。
- 同一器件的参数 ID 连续分配、不跳号；作废参数保留行并标「作废」，序号不回收。

> 示例，非真实器件参数：R = 10 kΩ ±1 % @ 25 ℃——仅示范字段如何填写，禁止引用为真实保证值。

类型标注写法：参数值后统一加来源标记，且只能取六类取值之一——保证值 / 典型值 / 读图值 / 计算值 / 工程假设值 / 待确认值，口径与 [[元器件知识库数据分类与来源规则]] 一致。六类之外的表述（如「大概」「参考值」）不得使用。

### 单一事实来源

本节是参数定义与参数 ID 的唯一定义处：参数的中英文名、符号、单位、参数定义、物理意义、影响因素只在这里写一次；案例文档与 WCCA 文档只引用参数 ID，不重复维护同一参数事实。不重复的边界是「定义」与「口径」——同一参数在不同型号下的具体取值由案例文档以数据记录 ID 登记，不算重复维护。

## 器件概述
填写指引：
- **器件类别 ID**：在本节首句后标注本类别的 ID（电阻类别示例为 RES），取值必须来自《元器件知识库统一ID规范》的类别注册表；未登记的类别先登记 ID 再写作。
- **器件定义**：一句话说明该器件在电路中的功能本质，不用市场宣传语。
- **工作原理**：用物理机制解释器件如何实现该功能，必要时给出等效电路或等效模型。
- **内部结构或等效模型**：说明关键结构（如介质层、沟道、磁芯）与其对参数的影响路径。
- **器件分类**：子类划分及其判据，避免与相邻类别混淆。
- **常见封装**：主流封装形式与适用场景，说明封装对散热与寄生参数的影响。
- **典型应用场景**：在 BMS 与车载电子中的典型位置（采样、驱动、滤波、隔离等）。

写作要求：本节只写通用规律，不出现具体型号与实测数值。

## 参数体系
填写指引：按下列参数类别分组，逐参数填满九列。九列为强制字段，首列是参数 ID，缺任一列视为未完成。模板示例行不得作为真实参数记录；复制使用时应替换示例值。

参数类别（逐类建表或建小节）：电气参数、额定参数、最大额定值（Absolute Maximum Ratings）、动态参数、温度相关参数、功耗及热参数、可靠性参数、其他特殊参数。

| 参数 ID | 英文名称 | 中文名称 | 符号 | 单位 | 参数定义 | 物理意义 | 影响因素 | 工程应用场景 |
|---|---|---|---|---|---|---|---|---|
| （如 RES-001，示例占位） | （英文标准名） | （中文名） | （符号） | （单位） | （一句话定义，说明测量条件） | （对电路行为意味着什么） | （温度/偏压/频率/老化等） | （选型、降额或 WCCA 中的用途） |
| RES-001（示例） | Rated Power（示例字段名） | 额定功率（示例） | P（示例） | W（示例） | 示例占用行，非真实器件参数 | 示例占用行 | 示例占用行 | 示例占用行 |

填写纪律：
- 只写保证值或已标注来源的典型值；本表只建口径与字段，具体量值一律进案例文档。
- 同名异义参数（不同厂商标注口径不同）必须注明采用哪一家的定义，并在案例文档登记对应数据记录 ID。
- 参数值与取值条件必须成对出现，不允许孤立数值。
- 参数 ID 一旦分配，不因改名、换节、重新排序而变化。

### 四层参数性质

参数必须按四层区分，不得混用；四层的含义与用途不同，混用是 WCCA 结论失真的首要原因。

| 层次 | 英文名 | 含义 | 能否作为正常工作条件 | 登记要求 |
|---|---|---|---|---|
| 绝对最大额定值 | Absolute Maximum Ratings | 器件不损坏的生存边界，通常是单参数瞬时极限 | 不可以 | 单独分组并标明「非工作条件」；只用于应力余量判断 |
| 推荐工作条件 | Recommended Operating Conditions | 原厂建议的长期工作范围 | 可以 | 标明为本器件设计工作区，WCCA 工作点必须落在其中 |
| 保证电气特性 | Guaranteed Electrical Characteristics | 在指定测试条件下原厂承诺的极值（Min 与 Max） | 可以（仅在给定条件内） | 逐参数标明 Min / Typ / Max 各列的性质 |
| 典型特性 | Typical Characteristics | 典型表现、典型曲线，不构成承诺 | 不可以作为边界 | 只标典型值或读图值，不得写成保证值 |

规则：
- 绝对最大额定值（AMR）不得当作正常工作条件使用：它既不是推荐工作点，也不是可以长期驻留的设计区间，只能用来回答「器件会不会损坏」。
- 设计点必须落在推荐工作条件内；超出推荐工作条件即使未超 AMR，也属于需要评审的越界使用。
- 保证电气特性只在标注的测试条件成立；条件外推必须走修正模型并标明修正模型 ID（示例 M-RES-001）。
- 典型特性只能用于敏感性分析与定性判断，典型值不得进入最坏情况计算。

### 参数相关性与耦合

- 参数不是彼此独立的：温度、偏压、频率、负载常常同时推动多个参数。例如温升会同时抬高电阻阻值并降低功率裕量。
- 本节逐组登记强相关参数对，写清相关方向、耦合机制与是否必须联合取值。
- 相关参数必须用参数 ID 表达（例如 RES-001 与 RES-004 在温升下同向漂移），用中文名对齐容易产生口径漂移。
- 单参数逐项取极值会高估或低估最坏情况；属于同一相关组的参数必须整组进入 WCCA，不得只取其一。

## Datasheet 阅读要点
填写指引，逐条回答：
1. **关键章节位置**：列出该器件关键参数通常出现在哪些章节（特性摘要、绝对最大额定值、推荐工作条件、电气特性、特性曲线、应用信息）。
2. **极值识别**：说明本器件常出现 Minimum / Typical / Maximum 三列中的哪几列，以及在只给典型值时如何处理（标典型值，不得升级为保证值）。
3. **测试条件读法**：列出该器件参数测试条件中最关键的几个维度（温度、输入电压、输出电压、电流或负载、频率、偏压），并说明偏离条件后如何估算。
4. **曲线与表格限制**：说明曲线是在什么基准条件下测得的，外推时的适用边界；曲线读数一律标读图值。
5. **保证值与典型值的区分**：逐参数标注是否为保证值，典型值不得进入最坏情况计算。
6. **需联合条件分析的参数**：列出必须同时考虑温度、电压、负载的参数，并指向「参数相关性与耦合」小节。

结论要可操作：读者读完应能直接在 Datasheet 中定位并判断取值，并能说出该数值属于六类取值中的哪一类。

## 工程设计应用
填写指引：
- **器件选型原则**：按功能需求到参数的映射给出选型顺序，先筛什么后筛什么。
- **典型应用电路**：给电路拓扑描述与关键节点作用，必要时配简图说明。
- **参数选择注意事项**：容易选错的参数与常见误判（例如把典型值当保证值、把 AMR 当工作区）。
- **电气应力评估**：电压、电流、功率、瞬态应力的核算方法。
- **温度与功耗影响**：自温升与周边热源的影响路径。
- **降额设计**：本器件应降额的对象与降额依据来源。
- **常见设计错误**：逐条给出错误现象、后果与正确做法。

每条工程结论都要标注依据（Datasheet 章节、厂商应用笔记或标准条文），不允许只给结论。

## WCCA 关联
填写指引：
- **参与计算的参数清单**：列出进入最坏情况分析的参数及其参数 ID。
- **分析目标 ID**：每个分析目标（例如某节点输出上限、某支路电流上限）登记一个分析目标 ID，示例为 WCCA-RES-001；一个目标一行，不得把多个目标合并。
- **取极值方向**：逐参数说明取最小值还是最大值，并写明该方向由哪个分析目标与哪段电路关系推出，不允许凭习惯写结论。
- **参数相关性**：引用「参数相关性与耦合」小节登记的相关参数对，说明本目标下的联合取值方式。
- **工作条件影响**：温度、偏压、负载、频率对参数的影响方式与修正入口（修正模型 ID 示例 M-RES-001）。
- **公式 ID**：计算式以公式 ID 引用（示例 W-RES-001），公式正文登记在 08_WCCA_Knowledge 方法文档；本节只写本器件在公式中的角色，不复制推导过程。
- **映射记录**：每个参与计算的参数在映射总表登记一行，并回填该映射行的映射记录（映射行以分析目标 ID、数据记录 ID 与公式 ID 三者的组合唯一定位），保证「本节参数 → 映射行 → 公式」可逐行核对。
- **Datasheet 数据来源**：每个参数对应的页码与表号或曲线号，或直接给出数据记录 ID。
- **不可直接用于计算的参数**：说明原因与替代处理（如改用工程假设值并标注评审记录）。

参数映射统一按 09_Templates/WCCA参数映射模板.md 的表格登记，本节的映射行要与该表一致；映射与公式只引用 ID，不重复维护同一参数事实。
