# WCCA参数映射模板

## 使用说明
本模板用于把器件参数登记为可参与 WCCA 计算的映射行，是通用知识文档与 WCCA 方法文档之间的桥梁。

使用步骤：
1. 复制「参数映射总表」的表头到 08_WCCA_Knowledge/元器件WCCA参数映射表.md，或在本器件类别的小节内使用。
2. 每个映射场景各占一行；先填写映射 ID、分析目标、器件型号、参数、数据记录、公式和工作条件等字段，无法填写的列写「待确认」并登记原因；无法填写的列写「待确认」并登记原因。
3. 取值依据列必须写明为什么取 Min 或 Max，并指出由哪个分析目标与哪段电路关系推出，不允许只写结论。
4. 修正模型 ID 列要指向具体修正模型登记条目，保证可复现。
5. 登记完成后回到器件入口文档的「WCCA 关联」节，保持两处引用一致。
6. 表内只写 ID 与结论，公式正文与参数定义分别登记在各自唯一位置（见 [[元器件知识库统一ID规范]] 的登记位置表）。

### 映射行标识与单一事实来源

- 每个映射行必须有独立 Mapping ID。分析目标 ID、器件型号 ID、参数 ID、数据记录 ID、公式 ID 与工作条件/场景共同描述该行；同一目标、数据记录和公式在不同温度/电压/负载或场景下可重复出现，因此不得用三者组合充当唯一键。
- 本表只做映射：参数定义不在这里写（引用参数 ID），数值与测试条件不在这里写（引用数据记录 ID），公式推导不在这里写（引用公式 ID）。
- 单一事实来源：不重复维护同一参数事实，下游文档只引用 ID；发现与登记处不一致时以登记处为准并回改本表。

> 示例，非真实器件参数：R = 10 kΩ ±1 % @ 25 ℃——仅示范字段如何填写，禁止引用为真实保证值。

禁止事项：不得把典型值当作极值填入；不得写入未经 Datasheet 溯源的数值；不得跨分析目标套用极值方向。

复核要点：
- 每一行的 Min / Max 方向要能由具体分析目标与电路关系推出，不能凭习惯、不能沿用上一行结论。
- 取值类型只能取六类之一：保证值 / 典型值 / 读图值 / 计算值 / 工程假设值 / 待确认值；其中典型值与待确认值所在行不得进入正式结论。
- 同一参数在多个工作点使用时分行登记，不合并且不取平均。
- 公式 ID 必须在「计算公式」表中存在；修正模型 ID 必须在方法文档的修正模型登记表中存在。

### 极值方向由分析目标与电路关系确定

- 取 Min 还是取 Max，取决于该参数在目标电路中的传递方向：参数上升使被分析量变坏就取 Max，参数下降使被分析量变坏就取 Min。
- 因此同一参数在不同分析目标下极值方向可能相反（例如反馈分压上臂电阻在「输出上限」目标取 Max，在「输出下限」目标取 Min）；方向结论必须逐分析目标单独推导并写清传递路径。
- 方向推导必须给出电路关系：参数 → 电路节点 → 被分析量的增减 → 结论是否属于最坏情况。无法推出传递路径的，标待确认值，不得凭经验定方向。

### 参数相关性、联合工作条件与最坏组合

- **参数相关性**：同一器件内参数受共同物理因素驱动（温度、偏压、负载），不能各自独立取极值。相关参数组由器件入口文档的「参数相关性与耦合」节登记。
- **联合工作条件**：最坏情况往往发生在条件组合上（例如高温 + 高负载 + 低压输入），而不是单一条件的极值。映射行必须写明所处工作条件，联合条件另立行登记。
- **最坏组合处理规则**：
  1. 先按分析目标列出全部相关参数组，组内参数联合取值，组间按可同时发生的条件组合；
  2. 对每个组合计算并比较，取使被分析量最不利的组合作为结论依据；
  3. 组合数过多时按敏感性排序取前若干组合，并声明截断准则与漏检风险；
  4. 不得把不可能同时发生的条件叠加成「伪最坏组合」；叠加前须说明物理可行性。

## 参数上下限来源
填写指引：说明每个取值的来源等级，来源等级决定该行能否直接用于计算。来源等级与《元器件知识库数据分类与来源规则》的六类取值一一对应，不得自创第七类。

| 取值类型 | 含义 | 可否直接用于 WCCA | 登记要求 |
|---|---|---|---|
| 保证值 | 原厂在指定条件下承诺的极值 | 可以 | 登记数据记录 ID、页码与表号 |
| 典型值 | 原厂给出的典型表现 | 不可以 | 标注典型值并说明替代方案；不得进入正式结论 |
| 读图值 | 从原厂曲线读出的数值 | 不可以直接使用 | 登记读点位置、读取误差与适用区间 |
| 计算值 | 由保证值经公式推导 | 可以 | 给出公式 ID、输入参数 ID 与计算过程 |
| 工程假设值 | 资料不足时的临时取值 | 需评审后使用 | 写明评审记录编号、假设理由与适用边界 |
| 待确认值 | 尚未取得或存在争议 | 不可以 | 登记到待确认清单，责任人跟进 |

纪律：
- 典型值与待确认值不得进入正式 WCCA 计算结论，只能作为敏感度分析的输入，并在结论中显式标注未覆盖。
- 工程假设值必须有评审批准记录与适用边界，缺评审记录的假设值按待确认值处理。
- 读图值转成可用边界前，必须先按工程假设值走评审，不得直接当作保证值。

## 温度与偏压修正
填写指引：每条修正记录都必须包含输入参数、适用条件、公式、出处四要素，缺一要素不得使用该修正结果。

| 修正条目 | 输入参数 | 适用条件 | 修正公式 | 出处 | 修正模型 ID |
|---|---|---|---|---|---|
| （温度修正 / 偏压修正 / 自温升折算） | （参与修正的参数 ID 与其来源数据记录 ID） | （温区、偏压范围、负载范围；超出即失效） | （含符号表达式及系数取值来源） | （Datasheet 页码、应用笔记编号或方法文档条目） | （示例 M-RES-001） |

要点：
- **温度修正**：给出修正公式与适用温区，标明温度系数来源（Datasheet 表格或曲线）。
- **偏压修正**：说明哪些器件参数随偏压显著变化（如陶瓷电容的有效电容量），修正依据取哪张曲线，并声明读到的是读图值。
- **自温升**：自温升属于工作条件的一部分，不能用环境温度代替。引脚温度须按「环境温度 + 自温升」估算，自温升的计算式与热阻来源必须登记；无法取得热阻时标待确认值。
- **修正顺序**：规定先修正哪个因素、是否可叠加、是否需迭代；顺序不同结果不同时，取保守顺序并说明。
- **不适用区间**：明确修正公式在哪些条件下失效，失效时的替代处理。

每个修正动作都要指向可复现的公式与出处，禁止只写「按经验修正」。

## 计算公式
填写指引：逐式给出，标明符号、单位、适用条件与判定依据。编号列改为公式 ID，公式正文与推导过程登记在 08_WCCA_Knowledge 方法文档，本表只做映射与判定，不重复维护公式内容。

| 公式 ID | 计算目标 | 公式 | 符号定义 | 输入参数 ID | 输出/分析目标 ID | 适用条件 | 判定依据 | 出处 |
|---|---|---|---|---|---|---|---|---|
| （示例 W-RES-001） | （如 分压输出极值） | （含符号表达式） | （逐符号说明含义与单位） | （示例 RES-001） | （本式输出量对应的参数 ID 或分析目标 ID） | （工作条件与前提） | （裕量阈值来源与判据，指向分析目标 ID） | （方法文档条目或标准条文） |

要求：
- 公式中用到的每个输入参数都必须能在「参数映射总表」中找到对应行，并以参数 ID 引用。
- 计算推导值必须保留输入数据与计算过程：列明每个输入的数据记录 ID、取值与取值类型，列明中间量，结论可被第三人按同一路径复现。
- 公式结果应归属于已定义的分析目标 ID；参数 ID 仅标识器件参数定义。若确需为派生结果建立独立结果 ID，必须先在统一 ID 规范登记其类别与规则，不得直接把未定义的「输出参数 ID」当作已存在的 ID 类型。
- 给出计算结果的判定口径（裕量阈值来自哪里）；阈值不得来自经验或口头约定。
- 若公式为近似式，写明近似条件与误差方向。
- 公式只在方法文档维护一份，本表只引用公式 ID，不复制推导：避免同一公式出现多个版本。

## 不可直接用于计算的参数
填写指引：列出不能直接进入最坏情况计算的参数，并给出替代处理。

| 参数 | 不可用的原因 | 替代处理 | 风险提示 |
|---|---|---|---|
| （参数名，给参数 ID） | （仅有典型值 / 读图值误差过大 / 定义口径不一致 / 强依赖未控制条件） | （改用工程假设值并标注 / 增加实测 / 换用有保证值的型号） | （对结论保守性的影响方向） |

要求：
- 每条都要说明「如果不处理会产生什么偏差」，偏差方向要写清是偏乐观还是偏保守。
- 处理决定必须经评审确认后方可写入正式分析；未经评审的处置只能停留在本表。
- 典型值不得通过「四舍五入到偏保守一侧」的方式伪装成保证值。
