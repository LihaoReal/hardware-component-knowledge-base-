## 统一 ID 规范引入说明

本次修订引入 8 类统一 ID，目的是让四条追溯链在模板层就具备可核对的接口：

1. **器件类别 ID**：把 19 个器件类别入口文档与类别前缀绑定，后续所有参数、型号、公式 ID 都必须使用注册表内的类别前缀，禁止自创。
2. **参数 ID**：参数定义的唯一锚点。通用知识模板登记一次，案例模板与 WCCA 模板只引用。这样同一参数在不同型号、不同分析目标下不会出现多套口径。
3. **器件型号 ID 与 Datasheet ID**：把「型号」与「文档」分离。同一型号可以有多份 Datasheet，同一 Datasheet 也可能覆盖多个订货号，两者不能合并成一个标识。
4. **数据记录 ID**：以 Datasheet ID 为父级，把「某份文档里的某一行原始数值」变成可引用对象。所有下游引用（映射、计算、结论）都指向数据记录，而不是复述数字。
5. **公式 ID、分析目标 ID、修正模型 ID**：把「算什么」「为什么这样取」「怎么修正」三件事分离登记，避免公式在多处重复维护。

配套约束：
- ID 一旦分配不得因改名、移动或版本更新而改变；废弃 ID 不得重新分配。
- 不重复维护同一参数事实，下游只引用 ID。
- 模板中的示例 ID 统一使用电阻类别（RES 前缀），避免示例本身引入未注册类别。
