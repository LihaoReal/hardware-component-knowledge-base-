# 知识库质量检查

## 检查维度
固定五个检查维度，每类器件文档完成后逐维检查：

| 维度 | 检查内容 | 检查方法 |
|---|---|---|
| 完整性 | 章节齐全、参数清单无缺项、关联文档链接齐全 | 对照模板章节逐项核对，缺章节即不合格 |
| 参数准确性 | 数值与 Datasheet 一致、极值方向正确、单位与符号统一 | 抽查参数回溯到页码与表号，逐项比对 |
| 可追溯性 | 每个数值都有出处与测试条件 | 随机抽取若干参数按出处复核 |
| 链接有效性 | 无断链、无孤立文档、索引与目录一致 | 逐条打开双链核对，检查每个文档的入链 |
| 一致性 | 同类器件在不同文档中的同名参数口径一致 | 交叉比对入口文档、案例文档与映射表 |

## 检查清单
逐项勾选，全部勾选后方可标记该文档为 reviewed：

- [ ] 文件 Frontmatter 八个字段齐备，type、category、status 取值正确
- [ ] 文件恰好一个一级标题，文字与文件名一致
- [ ] 二级标题与模板完全一致，顺序未变，未增删章节
- [ ] 每个二级标题下都有实质内容，无空白章节
- [ ] 参数体系按八字段展开，无缺列
- [ ] 所有数值都标注来源类型（保证值 / 典型值 / 设计参考值 / 计算值 / 工程假设值 / 待确认值）
- [ ] 所有数值都附测试条件与 Datasheet 出处
- [ ] 无未经溯源的推测数值，无把典型值当保证值的表述
- [ ] WCCA 关联节与映射表内容一致
- [ ] 关联文档链接全部有效，无断链
- [ ] 该文档至少被一个其他文档链接
- [ ] 已确认与待确认事项已登记到待确认问题清单
