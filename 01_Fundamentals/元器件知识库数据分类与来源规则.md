# 元器件知识库数据分类与来源规则

## 本文范围

本规范回答三个问题：某个数值**是什么性质**、**从哪来**、**能不能进入 WCCA 结论**。它约束三个模板与全部知识文档的取值标注方式。

读者对象：撰写器件通用知识文档、Datasheet 案例文档、WCCA 映射文档的全部工程师与 Agent。

配套文档：标识与登记规则见 [[元器件知识库统一ID规范]]；参数口径分组见 [[参数分类与定义]]。

## 六类取值

全库只允许六类取值，任何数值都必须归入其中一类并显式标注。六类互斥、不交叉。

| 取值类型 | 定义 | 典型来源 | 可否进入 WCCA 结论 | 必填配套信息 |
|---|---|---|---|---|
| 保证值 | 原厂在明确测试条件下承诺的极值（Min 或 Max） | Datasheet 电气特性表的 Min/Max 列 | 可以 | 测试条件、页码与表号、数据记录 ID |
| 典型值 | 原厂给出的典型表现，通常为 Typ 列或特性曲线标称点 | Datasheet Typ 列、厂商应用笔记 | 不可以，只能做敏感度分析 | 标注类型、说明替代方案 |
| 读图值 | 从 Datasheet 曲线目视或按刻度读出的数值，含读取误差 | 特性曲线、降额曲线、安全工作区图 | 不可以直接使用，须先转化为保证值或工程假设值 | 读点位置、读取误差、适用区间 |
| 计算值 | 由已登记数值经公式推导得到的数值 | WCCA 计算过程 | 可以，但须保留输入与过程 | 公式 ID、输入参数 ID、计算过程 |
| 工程假设值 | 资料不足或无法取得保证值时，经评审批准的临时取值 | 设计评审结论 | 有条件使用，须限定适用边界 | 评审记录编号、假设理由、适用边界 |
| 待确认值 | 尚未取得、存在争议或资料缺失的条目 | 缺口登记 | 不可以 | 缺口说明、责任人、确认依据、确认日期 |

规则：
1. 一个数值只能有一类性质。同一参数在不同文档中不得出现不同性质判定；若判定改变，必须回改登记处并记录修订原因。
2. Typ 列数值一律为典型值，即使原厂未写「典型」二字，也不得当作保证值引用。
3. 曲线上的数值一律为读图值，即使曲线标注了「typical」也不构成保证值。
4. 计算值必须由已登记 ID 的输入推导，不允许出现「黑箱结果」。
5. 工程假设值不带评审记录即视为待确认值，不得进入正式结论。

## 测试条件七要素

任何参数数值都必须成对给出测试条件。测试条件按七个要素记录，缺项写「未注明」而不是留空：

| 要素 | 记录内容 | 缺失时的处理 |
|---|---|---|
| 温度 | 环境温度或壳温/结温，注明是哪种温度 | 标「未注明」，该数值降级为待确认值 |
| 输入电压 | 施加在器件输入端的电压条件 | 标「未注明」 |
| 输出电压 | 输出端电压条件，用于输出特性类参数 | 标「未注明」 |
| 电流或负载 | 负载电流、负载电阻或负载率 | 标「未注明」 |
| 频率 | 测试信号频率或开关频率 | 标「未注明」 |
| 偏压 | 直流偏置电压（电容容值、磁芯磁导率类参数必填） | 标「未注明」，该参数不得当作保证值 |
| 其他必要条件 | 脉宽、占空比、气流、安装方式、老化时长等 | 标「未注明」 |

写法约定：七要素全部为「要素名：取值+单位」的显式形式，不写「常温」「典型条件」这类含糊表述；一项条件包含多要素时逐项列出。

## 单位、条件与出处的绑定

1. **原始单位优先**：直接抄录 Datasheet 的原始单位与数量级，不擅自换算。确需换算时，保留原始值与原始单位，并另起一列写换算值，注明换算依据。
2. **禁止插值**：表格只给离散点时不插值构造中间点；确需中间值时按计算值处理并保留插值方法。
3. **不合并多条件行**：同一参数在不同温度、不同偏压下的多行记录分别登记，不取平均、不合并。
4. **出处到页表号**：每个数值都要能指到页码与表号或曲线号；只有页码不够，必须到具体表或图。
5. **示例行标注**：模板与规范中的示例数值必须带「示例」「占位」「非真实」字样，禁止把示例数值当作真实参数引用。

## 别名与废弃术语登记

历史模板曾使用「设计参考值」表述厂商应用笔记或行业实践给出的推荐值。该表述已废止，原因是它把「来源」与「性质」混为一谈：同一个推荐值既可能是有条件保证值，也可能是工程假设值。

废止后的处理方式：
- 原「设计参考值」按性质拆分为保证值（有明确条件与原厂承诺）、工程假设值（经评审的临时取值）或待确认值（尚未确认），并各自按本规范标注。
- 三个模板中不再出现该词；旧文档回填时按上述规则逐条拆分，不做机械替换。

## 数据纪律

- 不得编造参数、型号或测试条件；查不到即写「未提供」或「待确认」，不填估算值充数。
- 不得把典型值或曲线读数写成原厂保证值；Typ 与读图值不得作为最坏情况边界。
- 不得把 Absolute Maximum Ratings 当作正常工作条件使用；它只用于判断应力是否超出器件生存极限。
- 不得脱离具体分析目标确定取 Min 还是取 Max；极值方向由分析目标与电路关系推出，并写明推理。
- 不得把规范条文原文抄进知识文档充作内容；知识文档写工程判断与出处，不写验收口径。
- 不得在库内新增程序文件或结构化数据文件；本阶段只用 Markdown 承载数据。

## 单一事实来源

- 同一参数事实只在一个登记位置维护（见《元器件知识库统一ID规范》的「ID 类型 → 唯一登记位置」表），下游文档只引用 ID，不重复复制数值、条件与定义。
- 发现两处不一致时，以登记处为准，回改引用方，并在 [[更新记录]] 登记修订。
- 派生结论必须能沿着 ID 链回溯：结论 → 分析目标 ID / 公式 ID → 数据记录 ID → Datasheet ID → 页码与表号。
