# Datasheet阅读方法

## 本文范围
说明如何从原厂 Datasheet 中定位关键参数、识别极值与典型值、读懂测试条件，并判断参数能否进入 WCCA 计算。
读者为负责器件选型与最坏情况分析的硬件工程师。

## 待建设内容清单
1. Datasheet 章节结构地图：特性、绝对最大额定值、电气特性、曲线、应用信息。
2. Minimum / Typical / Maximum 的判定方法与常见陷阱（Typ 不等于保证值）。
3. 测试条件的读法：环境温度、偏置、负载、频率、脉宽的约束。
4. 曲线与表格中的限制条件，以及温度降额曲线的使用方式。
5. 参数缺口的登记办法：未提供与待确认的处理规则。
6. 与 [[Datasheet案例模板]] 的字段对应关系。
