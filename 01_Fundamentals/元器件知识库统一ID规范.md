# 元器件知识库统一ID规范

## 本文范围

本规范定义全库统一的标识符（ID）体系，用于把「通用参数定义 → Datasheet 原始记录 → WCCA 映射行 → 分析目标与公式」四条追溯链串起来。

读者对象：
- 撰写器件类别入口文档的工程师（分配与登记参数 ID）；
- 撰写 Datasheet 案例文档的工程师（分配型号 ID、Datasheet ID、数据记录 ID）；
- 执行 WCCA 分析的工程师（引用分析目标 ID、公式 ID、修正模型 ID）。

本规范只规定标识与登记规则，不规定任何器件参数的具体数值口径。参数口径见 [[参数分类与定义]]，取值性质见 [[元器件知识库数据分类与来源规则]]。

## 设计原则

1. **先定义、后引用**：任何 ID 在首次使用前必须已在其唯一登记位置登记，否则视为悬空引用。
2. **ID 不可推断语义之外的信息**：ID 只承担唯一标识与追溯职责，不编码温度等级、精度等级、批次等易变属性。
3. **类别前缀唯一**：所有下游 ID 的第一段必须取自「器件类别 ID 注册表」，不得自行编造字母组合。
4. **结构化预留**：ID 的形态固定、长度固定、分隔符固定，便于后续按正则解析、按前缀聚合、按流水号排序；一旦需要引入数据库或检索工具，可直接由 Markdown 表格无损导入，不需要重命名已登记 ID。
5. **单一事实来源**：同一事实只在一处维护，其他文档只引用 ID，不复制数值与条件。

|---|---|---|---|---|
| 器件类别 ID | `^[A-Z]{2,4}$` | `RES` | 知识库维护人 | 本规范「器件类别 ID 注册表」 |
| 参数 ID | `^[A-Z]{2,4}-\d{3}$` | `RES-001` | 器件类别入口文档撰写人 | 器件入口文档「参数体系」表首列 |
| 器件型号 ID | `^PART-[A-Z]{2,4}-\d{3}$` | `PART-RES-001` | 案例文档撰写人 | 案例文档「案例元信息」 |
| Datasheet ID | `^DS-[A-Z]{2,4}-\d{3}$` | `DS-RES-001` | 案例文档撰写人 | 案例文档「案例元信息」 |
| 数据记录 ID | `^DS-[A-Z]{2,4}-\d{3}-P\d{3}$` | `DS-RES-001-P001` | 案例文档撰写人 | 案例文档「关键参数提取表」首列 |
| 公式 ID | `^W-[A-Z]{2,4}-\d{3}$` | `W-RES-001` | WCCA 方法文档维护人 | 08_WCCA_Knowledge 方法文档的公式登记表 |
| 分析目标 ID | `^WCCA-[A-Z]{2,4}-\d{3}$` | `WCCA-RES-001` | WCCA 分析负责人 | 08_WCCA_Knowledge 分析目标清单 |
| 修正模型 ID | `^M-[A-Z]{2,4}-\d{3}$` | `M-RES-001` | WCCA 方法文档维护人 | 08_WCCA_Knowledge/温度影响计算.md 修正模型登记表 |

### 器件类别 ID

- **格式定义**：`^[A-Z]{2,4}$`，纯大写字母 2~4 位，不带数字、不带连字符。取值必须来自本规范的类别注册表。
- **示例**：`RES`（电阻类别的示例占用值，非真实器件参数）。
- **分配方**：知识库维护人在新建器件类别入口文档时分配，分配动作与目录建档在同一次评审中完成。
- **唯一登记位置**：本规范「器件类别 ID 注册表」。入口文档正文只引用类别 ID，不重新定义。
- **不变性与不复用**：类别 ID 与目录结构解耦——目录改名、文档改名、分类层级调整都不触发重编；类别被合并或废弃时，原 ID 保留在注册表中标为「已废弃」，不得转让给新类别。

### 参数 ID

- **格式定义**：`^[A-Z]{2,4}-\d{3}$`，即「器件类别 ID + 连字符 + 三位流水号」。流水号在类别内从 001 连续分配，不跳号、不复用。
- **示例**：`RES-001`。
- **分配方**：器件类别入口文档撰写人，在「参数体系」表中首次登记该参数时分配。
- **唯一登记位置**：该器件类别入口文档的「参数体系」表首列。此处是该参数**唯一**的定义处：中文名、英文名、符号、单位、物理意义、影响因素只在这里写一次。
- **不变性与不复用**：参数改名（例如统一译名、改为 IEC 标准名）不得改变参数 ID；参数在文档内换节、换表、换排序位置也不得改变参数 ID。参数作废时保留行并标「已废弃」，其流水号不重新分配给其他参数。

### 器件型号 ID

- **格式定义**：`^PART-[A-Z]{2,4}-\d{3}$`，即 `PART-` + 器件类别 ID + 三位流水号。
- **示例**：`PART-RES-001`。
- **分配方**：案例文档撰写人，在建立该型号案例文档时分配；同型号不同封装视为不同型号，分别分配。
- **唯一登记位置**：`07_Datasheet_Cases` 下对应案例文档的「案例元信息」表。
- **不变性与不复用**：型号 ID 与订货型号文字解耦——订货型号补充包装后缀、补录完整料号、修正错别字都不触发重编。型号停产后 ID 保留，状态改「停产」，不得转让。

### Datasheet ID

- **格式定义**：`^DS-[A-Z]{2,4}-\d{3}$`，即 `DS-` + 器件类别 ID + 三位流水号。
- **示例**：`DS-RES-001`。
- **分配方**：案例文档撰写人，在录入第一份 Datasheet 时分配；同一器件类别下按录入顺序连续分配。
- **唯一登记位置**：案例文档「案例元信息」表（与器件型号 ID 同表登记，一行一文档）。
- **不变性与不复用**：Datasheet 版本更新（rev A → rev B）**不**分配新 ID，只更新「文档版本」字段并在修订说明中记录旧值；只有换成另一份独立文档（不同文档编号）时才分配新 ID。

### 数据记录 ID

- **格式定义**：`^DS-[A-Z]{2,4}-\d{3}-P\d{3}$`，即「父 Datasheet ID + `-P` + 三位记录流水号」。父级必须已登记的 Datasheet ID。
- **示例**：`DS-RES-001-P001`。
- **分配方**：案例文档撰写人在「关键参数提取表」每新增一行原始记录时分配；同一参数在不同测试条件下的多行记录各占一个 ID。
- **唯一登记位置**：案例文档「关键参数提取表」首列。该行同时是该条原始数值（含单位、测试条件、页码）的唯一事实来源。
- **不变性与不复用**：记录的读点误差修正、页码纠错、单位写法统一都属于同一记录的内容修订，ID 不变；记录被判定无效时保留行并标「作废」，ID 不回收。

### 公式 ID

- **格式定义**：`^W-[A-Z]{2,4}-\d{3}$`，即 `W-` + 器件类别 ID + 三位流水号。
- **示例**：`W-RES-001`。
- **分配方**：WCCA 方法文档维护人，在公式首次进入方法文档登记表时分配；跨类别通用公式归入其主用类别的流水段。
- **唯一登记位置**：`08_WCCA_Knowledge` 方法文档中的公式登记表。模板与案例文档只引用公式 ID，不复制公式正文的推导过程。
- **不变性与不复用**：公式记号替换、变量重命名、排版修订不改变公式 ID；公式失效或被更精确表达式取代时保留登记并标「已被替代」，新表达式分配新 ID。

### 分析目标 ID

- **格式定义**：`^WCCA-[A-Z]{2,4}-\d{3}$`，即 `WCCA-` + 器件类别 ID + 三位流水号。
- **示例**：`WCCA-RES-001`。
- **分配方**：WCCA 分析负责人，在一个分析目标（例如某节点的分压输出上限）立项时分配。
- **唯一登记位置**：`08_WCCA_Knowledge` 下的分析目标清单。任何映射行、结论行都必须回填该 ID。
- **不变性与不复用**：分析对象改名、所在原理图页号变化、分析报告升版都不改变分析目标 ID；分析目标关闭后 ID 归档，不重新启用。

### 修正模型 ID

- **格式定义**：`^M-[A-Z]{2,4}-\d{3}$`，即 `M-` + 器件类别 ID + 三位流水号。
- **示例**：`M-RES-001`。
- **分配方**：WCCA 方法文档维护人，在登记一个温度修正或偏压修正模型时分配。
- **唯一登记位置**：`08_WCCA_Knowledge/温度影响计算.md` 的修正模型登记表。
- **不变性与不复用**：模型拟合区间扩展、系数表更新属于同一模型的内容修订，ID 不变；模型被新模型替代时原 ID 标「已被替代」，新模型另分配。

## ID 类型 → 唯一登记位置

下表落实单一事实来源：每个 ID 类型只允许在一处定义，其他文档只引用。

| ID 类型 | 唯一登记位置（定义处） | 下游只引用不复制 | 违反后果 |
|---|---|---|---|
| 器件类别 ID | 本规范的类别注册表 | 入口文档、案例文档、WCCA 映射表 | 出现未注册类别前缀，追溯链断裂 |
| 参数 ID | 器件类别入口文档「参数体系」表 | 案例模板只引用参数 ID，不重写参数定义 | 同一参数两套中文名，统计口径冲突 |
| 器件型号 ID | 案例文档「案例元信息」 | WCCA 映射总表、Datasheet 出处登记 | 同一型号多份案例，重复提取 |
| Datasheet ID | 案例文档「案例元信息」 | 数据记录 ID 的父级、出处登记表 | 文档版本混叠，无法回溯修订 |

| 分析目标 ID | 08_WCCA_Knowledge 分析目标清单 | 映射总表、计算结论 | 结论无法归属到分析目标 |
| 修正模型 ID | 08_WCCA_Knowledge/温度影响计算.md 修正模型登记表 | 映射总表、修正记录 | 温度修正不可复现 |

## 编号与引用写法

1. **统一大写**：ID 一律大写字母与数字，不使用中文、不使用空格、不使用下划线。
2. **前缀写法一致**：同一 ID 类型在全库只能有一种前缀写法，例如数据记录一律 `DS-<类别>-<序号>-P<记录序号>`，不允许同时出现 `DR-`、`RECD-` 等变体。
3. **引用时写全 ID**：正文引用参数写 `RES-001`，不写「编号 1」或「第 1 个参数」。
4. **wikilink 与 ID 并存**：文档间跳转用双链（`[[电阻_索引]]`），文档内定位与机器检索用 ID；两者不互相替代。
5. **表格首列约定**：参数表、记录表、映射表均把 ID 放首列，便于按列排序与正则扫描。
6. **不做语义编码**：不在 ID 中编码精度等级、温度等级、批次；这些属性放独立字段，避免属性变更污染 ID。

## 不变性与不复用条款

- ID 分配后不得因文件改名、目录移动或版本更新而改变。改名与移动只影响呈现层，不影响标识层。
- 废弃 ID 不得重新分配。作废条目保留原行，状态字段标「作废」或「已废弃」，并在修订说明中写明作废原因与替代 ID（如有）。
- 一段流水号区间内的作废条目形成「永久空洞」，这是有意设计：空洞保留了历史可追溯性，比连续编号更重要。
- 批量重编号（例如为了美观而整体压缩流水号）一律禁止；确因注册表结构性错误需要纠正时，必须走一次显式修订并保留新旧对照表。

## 结构化数据预留与单一事实来源

- 全部 ID 由固定正则约束，字段分隔符固定，因此 Markdown 表格即为结构化数据的唯一载体。本阶段不引入数据库、不开发计算程序，也不在库内保存 `.py`、`.json`、`.csv` 等派生文件。
- 单一事实来源（SSOT）：不重复维护同一参数事实——参数定义只在通用知识文档写一次，案例文档只登记原始记录，WCCA 只做映射与计算。任何文档发现与登记处不一致时，以登记处为准并回改引用方。
- 派生数据（平均值、拟合系数、修正后数值）必须标明由哪些 ID 派生而来，保证「结论 → 数据记录 ID → Datasheet ID → 页表号」可逐级回溯。
- 后续若接入检索或计算工具，只做「读取现有表格并建立索引」，不改动已登记 ID。

## 版本与变更

- 本规范新增 ID 类型属于结构变更，须升主版本号并经评审；补充示例、澄清措辞属于次版本变更。
- 注册表新增类别行必须与目录建档在同一次变更中提交，并在 [[更新记录]] 登记。
