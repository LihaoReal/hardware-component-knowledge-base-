# 光耦_索引

## 器件概述
本节 Phase 1 要写：光耦的器件定义、工作原理、内部结构或等效模型，以及在 BMS 与车载电子中的典型应用场景。
只写通用规律，不写具体型号数据；具体型号归入 Datasheet 案例文档。

## 分类与常见封装
本节 Phase 1 要写：光耦的常见子类划分与命名习惯，主流封装形式，以及封装对散热、寄生参数与装配工艺的约束。
封装尺寸、耐压等级与工艺差异按厂商标注整理，来源与页码登记到案例文档。

## 参数体系
本节 Phase 1 要写：光耦的电气参数、额定参数、最大额定值、动态参数、温度相关参数、功耗及热参数、可靠性参数的完整清单。
每个参数按 [[元器件通用知识模板]] 的八个字段展开：英文名称 / 中文名称 / 符号 / 单位 / 参数定义 / 物理意义 / 影响因素 / 工程应用场景。
具体量值留待 Phase 1 依 Datasheet 填写，本节只建立字段与口径。

## Datasheet 阅读要点
本节 Phase 1 要写：光耦的关键参数在 Datasheet 中的章节位置，Minimum / Typical / Maximum 的识别方法，测试条件的读法，以及曲线与表格中的限制条件。
同时标注哪些参数属于保证值、哪些只是典型参考值；方法论见 [[Datasheet阅读方法]]。

## 工程设计应用
本节 Phase 1 要写：光耦的选型原则、典型应用电路、参数选择注意事项、电气应力评估、温度与功耗影响、降额设计要点、常见设计错误。
工程结论必须给出依据来源（Datasheet 章节或厂商应用笔记），不允许只给结论。

## WCCA 关联
本节 Phase 1 要写：光耦参与最坏情况分析的参数清单，每个参数取最小值还是最大值的判据，温度与偏压修正方式，对应计算公式，以及哪些参数不能直接进入计算。
参数映射统一登记到 [[元器件WCCA参数映射表]]，方法框架见 [[WCCA基础方法]]。

## 常见失效模式
本节 Phase 1 要写：光耦的典型失效机理、应力诱因、失效表现、在线与离线筛查手段，以及与 DFMEA 关注项的对应关系。
失效判据必须可追溯到 Datasheet、厂商应用笔记或行业标准条文。
